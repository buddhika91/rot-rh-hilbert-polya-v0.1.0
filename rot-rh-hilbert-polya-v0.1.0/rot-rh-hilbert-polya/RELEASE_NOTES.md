# Release notes — v0.1.0

This is the first GitHub-ready packaging of the current ROT–RH Hilbert–Pólya v97–v100.1 operator/Fredholm program.

The release preserves the recovered historical research scripts byte-for-byte, adds reusable reference utilities, documents the exact Fredholm target and theorem gaps, records the reported v98–v100.1 benchmark, and adds source-integrity/firewall tests.

The release deliberately labels the result **not an RH proof**. The exact Xi determinant identity and global cutoff-independent operator limit remain open.
