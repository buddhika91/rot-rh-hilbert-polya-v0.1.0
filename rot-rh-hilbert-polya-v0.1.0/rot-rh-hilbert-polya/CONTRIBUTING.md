# Contributing

Contributions are welcome when they preserve the scientific firewall.

- Do not tune pre-freeze construction parameters using Xi or known zero errors and then report the same run as blind.
- New heavy experiments should save their complete command line, manifest and hash.
- Numerical cancellation claims should include precision/refinement controls.
- A `PASS` audit means only that the stated finite numerical gates passed; it must not be renamed an RH proof.
- Add fast tests for any reusable mathematical formula.
